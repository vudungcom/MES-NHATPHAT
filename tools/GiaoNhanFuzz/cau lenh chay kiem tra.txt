== 2. KIỂM NGẪU NHIÊN ==
dotnet bin2\GiaoNhanFuzz.dll <số PO> <thao tác mỗi PO> <seed>
-> cuối phải ra: SAI: 0
-> trong lúc chạy, khoảng 5 giây in 1 dòng: đã chạy x/y PO · sai n · ... giây · còn khoảng ... giây

Gợi ý:
dotnet bin2\GiaoNhanFuzz.dll 20 100 1      (thử nhanh)
dotnet bin2\GiaoNhanFuzz.dll 100 120 1     (kiểm vừa)
dotnet bin2\GiaoNhanFuzz.dll 300 120 2     (kiểm kỹ, lâu)

Lưu ý:
- Số thứ 2 là thao tác CHO MỖI PO, giữ 100-150. Muốn kiểm kỹ thì tăng số PO hoặc đổi seed.
- Cùng câu lệnh luôn ra cùng kết quả (để tái hiện lỗi). Đổi seed = bộ tình huống khác.
- Dừng giữa chừng: Ctrl+C. Dòng tiến độ cuối cùng vẫn cho biết đến lúc đó sai bao nhiêu.
- Có SAI khác 0: chụp màn hình + gửi đúng câu lệnh (nhất là seed).

== 3. ĐỔI KIỂU THAO TÁC (chỉ có tác dụng trong cửa sổ cmd đang mở) ==
set EXCL=0.7      70% PO có máy loại trừ (giao theo NC / trả về NC). Tắt: set EXCL=
set NGREP=60      tăng báo hàng lỗi sau nhận + huỷ báo lỗi. Tắt: set NGREP=
set PHOI=20       tăng Kho sửa phôi nhận. Tắt: set PHOI=
set LOI=1         (mới 28/10) thử nặng hàng lỗi: chọn thao tác có hàng thật để làm (ít bỏ qua), NG nhiều hơn, nhiều phiếu Hàng lỗi / Hàng sửa,
                  không sửa phôi (trừ khi đặt PHOI). Lưu được gấp nhiều lần lệnh thường. Tắt: set LOI=
                  Không đặt LOI thì lệnh thường chạy y như bản cũ (cùng seed ra cùng kết quả).

== VÒNG MÃ VỤ LỖI (28/10) ==
Mọi lượt ngẫu nhiên nay kiểm thêm sau MỖI thao tác: cân từng vụ lỗi (sinh ra = đang giữ + đang chuyển + đã xử lý + huỷ + trả khách),
mỗi nhóm Σ vụ đang giữ = ô Tồn hàng lỗi / Tồn hàng sửa của sổ, không vụ nào âm ở nơi nào, không còn hàng lỗi chưa gắn vụ (PO mới),
nhận / báo lỗi / hàng lỗi công đoạn trước thiếu loại lỗi hoặc loại lỗi đã ngưng phải bị chặn.
VU=0 để tắt kiểm "không còn hàng lỗi chưa gắn vụ" (khi muốn thử dữ liệu kiểu cũ).
